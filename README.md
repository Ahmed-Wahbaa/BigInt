# BigInt C++

A C++ implementation of a BigInt class that supports operations
on integers larger than the standard C++ integer limits.

## Features
- Addition and subtraction
- Multiplication
- Integer division
- Modulus
- Comparison operators
- Increment and decrement
- Unary operators
- Stream input/output
